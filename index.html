Qué cambió

El token público sigue sirviendo para identificar el proyecto, pero ya no concede permisos personales. El backend `forge-auth` valida un JWT de usuario real y consulta la lista privada `forge_authorized_users`. Publisher y Safety ya fueron endurecidos para exigir ese usuario autorizado.
